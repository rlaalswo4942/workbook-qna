# 부록 E. 주차별 제출 양식과 평가 루브릭

> **1장부터 매주 사용한다.** 회고 양식은 10주 내내 같다.

---

## E.1 제출물 구성

| 주차 | 제출 방법 | 내용 |
|---|---|---|
| 1주차 | 폴더 압축 (`week01_학번_이름.zip`) | 결과물 + `회고.md` |
| 2주차~ | **GitHub 저장소 링크** | 저장소에 결과물 + `회고.md` 포함 |
| 2주차~ | (함께) **배포 링크** | GitHub Pages 주소 |

2장에서 GitHub를 배우면 제출은 **링크 두 개**로 끝난다. 매주 압축해서 올리지 않는다.

 요약하거나 다시 쓰지 않는다. 실제로 보낸 문장이 중요하다.)

### 프롬프트 1

(여기에 붙여넣기)

## E.3 주차별 평가 루브릭

매주 **20점**으로 평가한다.

| 항목 | 배점 | 평가 기준 |
|---|---|---|
| **결과물** | 8점 | 그 주의 목표 기능이 작동하는가 |
| **프롬프트 기록** | 4점 | 요청이 구체적이고, 왜 그렇게 요청했는지 설명되는가 |
| **막힌 점 기록** | 4점 | 문제를 특정하고 해결 과정을 설명하는가 |
| **코드 설명** | 4점 | 자기 말로, 내용이 맞게 설명하는가 |

### 항목별 세부 기준

**결과물 (8점)**

| 점수 | 기준 |
|---|---|
| 7~8 | 목표 기능이 모두 작동하고, 수업에서 다루지 않은 시도가 보인다 |
| 5~6 | 목표 기능이 작동한다 |
| 3~4 | 일부만 작동하거나 에러가 있지만, 구조는 잡혀 있다 |
| 1~2 | 제출했지만 거의 작동하지 않는다 |
| 0 | 미제출 |

**프롬프트 기록 (4점)**

| 점수 | 기준 |
|---|---|
| 4 | 구체적인 요청이고, 그렇게 요청한 이유가 설명된다 |
| 3 | 요청은 구체적이지만 이유 설명이 얕다 |
| 2 | "만들어 줘" 수준의 막연한 요청만 있다 |
| 1 | 형식만 채웠다 |
| 0 | 없음 |

**막힌 점 기록 (4점)**

| 점수 | 기준 |
|---|---|
| 4 | 문제를 정확히 특정하고, 시도한 것과 해결 과정이 구체적이다 |
| 3 | 문제와 해결은 썼지만 과정이 단순하다 |
| 2 | "안 돼서 AI에게 물어봤다" 수준 |
| 1 | "별로 안 막혔다"만 썼다 |
| 0 | 없음 |

> **중요** — 이 항목은 **못 뚫어도 만점이 가능하다.** 무엇이 왜 막혔는지 특정하고, 시도한 것을 구체적으로 적었다면 그것이 이 수업에서 요구하는 능력이다. 반대로 "아무 문제 없었다"는 기록은 낮은 점수를 받는다.

**코드 설명 (4점)**

| 점수 | 기준 |
|---|---|
| 4 | 자기 문장으로 쓰였고, 설명 내용이 정확하다 |
| 3 | 자기 문장이지만 일부 부정확하다 |
| 2 | AI 설명을 조금 손본 수준이다 |
| 1 | AI 설명을 그대로 붙였다 |
| 0 | 없음 |

## E.4 감점과 부정행위

| 사유 | 처리 |
|---|---|
| 지각 제출 | 1일당 10% 감점 |
| 파일/폴더 이름 규칙 위반 (한글·공백) | 1점 감점 |
| 회고 파일 누락 | 해당 항목 0점 |
| 회고 파일 전체를 AI가 작성 | 회고 항목 전체 0점 |
| 타인의 저장소·결과물 복제 | 해당 주차 0점 |
| 반복 시 | 성적 처리 규정에 따름 |

**AI 사용 자체는 감점 사유가 아니다.** 결과물과 코드는 AI와 함께 만드는 것이 이 수업의 전제다. 다만 **회고는 본인이 쓴다.**

## E.5 제출 전 공통 체크리스트

매주 제출 직전에 확인한다.

- [ ] Live Server로 열어서 에러 없이 작동한다
- [ ] 브라우저 개발자 도구 콘솔에 빨간 에러가 없다 (7장 이후 필수)
- [ ] 폴더·파일 이름에 한글과 공백이 없다 (`회고.md`는 예외)
- [ ] `회고.md`의 1·2·3 항목이 모두 채워져 있다
- [ ] 연습용 파일(`test.txt`, `복사본` 등)을 지웠다
- [ ] (2주차~) 저장소 링크와 배포 링크가 **다른 사람이 열어도 열린다** — 로그아웃 상태나 휴대폰에서 한 번 확인한다
