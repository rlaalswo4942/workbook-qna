# 부록 A. 도구별 안내 — 내 AI를 에디터에 연결하기

> **1장에서 사용한다.** 자기가 쓰는 도구 항목만 찾아 따라 하면 된다.
>
> ⚠️ AI 도구의 화면과 메뉴 이름은 자주 바뀐다. 아래 설명과 다르면 **메뉴 이름보다 목적을 기준으로** 찾는다: ① AI 채팅창을 띄우고 ② 모드를 "에이전트"로 바꾸는 것, 이 두 가지만 하면 된다. 끝까지 안 되면 각 항목의 공식 문서 링크를 본다.

---

## A.0 공통 — 이 수업이 요구하는 최소 조건

| 조건 | 확인 방법 |
|---|---|
| 에디터 안에 AI 채팅창이 있다 | 사이드바나 패널에 채팅 입력창이 보인다 |
| **AI가 파일을 직접 고칠 수 있다** | 요청하면 파일이 실제로 생성/수정된다 |
| 수정 내용을 승인/취소할 수 있다 | 변경 부분이 색으로 표시되고 Accept/Discard가 있다 |

**연결 확인 테스트 (어느 도구든 공통)**

폴더를 연 상태에서 채팅창을 에이전트 모드로 두고 아래를 보낸다.

```
지금 열려 있는 폴더에 test.txt 파일을 만들고, 안에 "연결 성공"이라고 써 줘.
```

파일이 실제로 생기면 통과. 채팅창에 코드만 보여 주고 파일이 안 생기면 아직 에이전트 모드가 아니다.

확인 후 `test.txt`는 지운다.

## A.1 VS Code + GitHub Copilot

가장 흔한 조합이다. 학생은 **GitHub Student Developer Pack**으로 무료로 쓸 수 있는 경우가 많으니 먼저 확인한다.

### 설치와 로그인

1. VS Code를 열고 `Ctrl+Shift+X` → 확장 검색창에 **`GitHub Copilot`**
2. **GitHub Copilot** 설치 (Copilot Chat이 따로 보이면 그것도 함께 설치)
3. 설치가 끝나면 VS Code 오른쪽 아래 또는 상단에 로그인 안내가 뜬다 → **Sign in to GitHub** → 브라우저에서 승인
4. 왼쪽 세로 막대 또는 상단에 **Copilot 채팅** 아이콘이 생긴다

### 에이전트 모드 켜기

1. Copilot 채팅창을 연다 (`Ctrl+Alt+I` 또는 Copilot 아이콘)
2. 채팅 **입력창 아래쪽/왼쪽의 모드 선택** 메뉴를 찾는다 — `Ask` / `Edit` / `Agent` 중에서 고를 수 있다
3. **`Agent`** 를 선택한다
4. 그 옆에서 모델도 고를 수 있다. 코드 작업에는 성능 좋은 모델을 고르는 게 유리하다

> `Agent` 항목이 안 보이면 VS Code를 최신 버전으로 업데이트한다 (**도움말 → 업데이트 확인**). 에이전트 모드는 비교적 최근에 들어온 기능이라 구버전에는 없다.

### 학생 무료 혜택 확인

[education.github.com/pack](https://education.github.com/pack) 에서 학교 이메일이나 학생증으로 인증하면 Copilot을 포함한 혜택을 받을 수 있다. 심사에 며칠 걸릴 수 있으니 수업 전에 신청해 둔다.

공식 문서: [code.visualstudio.com/docs/copilot/overview](https://code.visualstudio.com/docs/copilot/overview)

## A.2 Cursor

Cursor는 VS Code를 기반으로 만든 별도 에디터다. 생김새와 조작법이 VS Code와 거의 같아서, **본문의 모든 설명이 그대로 통한다.**

### 설치

1. [cursor.com](https://cursor.com) → **Download for Windows**
2. 설치 후 실행 → 계정 만들기 또는 로그인
3. 처음 실행하면 "VS Code 설정을 가져올까요?" 라고 묻는다. VS Code를 쓰던 사람은 가져오면 편하다

### 에이전트 모드 켜기

1. `Ctrl+L` (또는 오른쪽 사이드바)로 채팅 패널을 연다
2. 입력창 근처의 모드 선택에서 **`Agent`** 를 고른다
3. 모델 선택 메뉴에서 쓸 모델을 고른다

### Cursor 사용자가 추가로 할 일

- **Live Server 확장은 똑같이 설치해야 한다.** `Ctrl+Shift+X` → `Live Server` 검색 → Install
- 본문에서 "VS Code"라고 쓰인 부분은 모두 "Cursor"로 읽으면 된다
- 단축키도 대부분 같다

공식 문서: [docs.cursor.com](https://docs.cursor.com)

## A.3 Claude Code (VS Code 확장)

터미널에서 쓰는 도구지만, VS Code 확장으로 설치하면 에디터 안에서 쓸 수 있다.

### 설치

1. VS Code에서 `Ctrl+Shift+X` → **`Claude Code`** 검색 → Install
2. 설치 후 안내에 따라 Claude 계정으로 로그인한다 (Claude 유료 플랜 또는 API 사용량 결제가 필요)
3. VS Code 안에 Claude Code 패널이 열린다

### 쓸 때 주의

- Claude Code는 **기본이 에이전트 방식**이다. 모드를 따로 바꿀 필요가 없다
- 파일을 수정할 때마다 승인을 요구한다. 내용을 보고 승인한다
- 반드시 **폴더를 열어 둔 상태**에서 쓴다. Claude Code는 열린 폴더를 작업 범위로 삼는다

공식 문서: [docs.claude.com/claude-code](https://docs.claude.com/en/docs/claude-code/overview)

## A.4 그 밖의 도구 (Codex, Gemini Code Assist 등)

| 도구 | 설치 방법 | 확인할 것 |
|---|---|---|
| **OpenAI Codex** (VS Code 확장) | 확장 검색 → `Codex` → Install → OpenAI 계정 로그인 | 파일을 직접 수정하는 모드가 있는지 |
| **Gemini Code Assist** | 확장 검색 → `Gemini Code Assist` → Google 계정 로그인 | Agent 모드 지원 여부 |
| **Windsurf** | [windsurf.com](https://windsurf.com) 에서 에디터 설치 | Cursor와 같은 방식. Live Server 별도 설치 |
| **Continue** 등 오픈소스 확장 | 확장 검색 후 설치, 모델 API 키 연결 | 에이전트 기능이 되는지 **반드시 확인** |

어떤 도구든 **A.0의 연결 확인 테스트를 통과하면 이 수업에 쓸 수 있다.** 통과하지 못하면 담당 교수에게 알린다.

## A.5 도구를 아직 못 정한 사람에게

판단 기준은 두 개다.

1. **지금 이미 구독하고 있는 게 있는가?** → 그걸 쓴다. 새로 결제할 필요 없다
2. **아무것도 없는가?** → 학생 인증으로 무료가 되는 **GitHub Copilot + VS Code** 조합부터 시도한다

무료 체험 기간이 있는 도구가 많다. 다만 **10주 동안 계속 쓸 수 있는 것**으로 정하는 게 좋다. 중간에 도구를 바꿔도 본문은 그대로 따라올 수 있지만, 설정을 다시 하는 시간이 아깝다.

## A.6 문제 해결

### 채팅창에 코드만 나오고 파일이 안 바뀐다
→ 에이전트 모드가 아니다. 모드 선택을 다시 확인한다. 선택 항목 자체가 없으면 에디터와 확장을 최신 버전으로 업데이트한다.

### 모드 선택 메뉴에 Agent가 없다
→ 버전이 낮다. **도움말(Help) → 업데이트 확인(Check for Updates)** → 재시작. 확장도 확장 패널에서 업데이트한다.

### 로그인이 계속 실패한다
→ 학교 와이파이가 막는 경우가 있다. 휴대폰 테더링으로 로그인만 한 번 성공시키면 이후에는 유지된다.

### AI가 "폴더를 찾을 수 없다"고 한다
→ 파일 하나만 열었다. **파일 → 폴더 열기**로 폴더째 다시 연다. VS Code 왼쪽 맨 위에 폴더 이름이 보여야 정상이다.

### AI가 엉뚱한 폴더를 고친다
→ 여러 폴더가 열려 있다. 창을 닫고 작업할 폴더 하나만 연다.

### 사용량(한도)을 다 썼다고 나온다
→ 무료/기본 플랜의 월 한도에 걸렸다. 다음 달까지 기다리거나 다른 도구로 전환한다. 이런 일이 생길 수 있으니 **과제는 마감 직전에 몰아서 하지 않는다.**

### 응답이 너무 느리다
→ 가벼운 모델로 바꿔 본다. 또는 요청을 작게 쪼갠다. "게임 전체를 만들어 줘"보다 "공 하나를 움직이게 해 줘"가 훨씬 빠르고 정확하다.
